# Плагины для КОМПАС-3D v25

| Плагин | Что делает |
|---|---|
| Чертежи рам | Чертежи рам из сборок `.a3d`: вид слева и вид справа, ординатные отметки, выноски, таблица профилей |
| Общий PDF стенок | Все стенки из папки — в один PDF с закладками |
| Проверка чертежа | Ищет наложения надписей, выход за рамку, пустые длины и т. п. |
| PDF из чертежей | Несколько `.cdw` — в один PDF |

## Установка на компьютер

1. [Скачать ZIP](https://github.com/greyka/kompas-plugins/archive/refs/heads/main.zip) и распаковать.
2. Закрыть КОМПАС.
3. Запустить `Установить.bat`. Python поставится сам (из интернета), права администратора не нужны.
4. КОМПАС → меню **Приложения** → нужный плагин.

## Менеджер плагинов и настройки

`Менеджер плагинов КОМПАС.exe` (ярлык на рабочем столе, или пункт «Настройки и версия…» в меню любого плагина):
список плагинов, все настройки, установленная и новая версия, кнопка «Обновить», журнал изменений.
Настройки лежат в `C:\KompasPlugins\settings.ini`, обновления его не трогают.

## Ошибки

При ошибке плагин показывает окно с кнопкой «Отправить разработчику»: описание, версия, компьютер и журнал
уходят в Telegram-бот @lider_house_debug_bot (общий с плагинами Archicad). Без ошибки — «Сообщить о проблеме…» в менеджере.
Журналы — `%LOCALAPPDATA%\KompasPlugins\logs\`. Разработчику забрать отчёты: `python _setup/report.py --inbox <папка>`.

## Обновление

Автоматически при входе в Windows: ярлык «Обновление плагинов КОМПАС» в Автозагрузке.
Вручную: `C:\KompasPlugins\Обновить.bat`. Git на компьютере не нужен.

Подробно — в [ПРОЧТИ.txt](ПРОЧТИ.txt).

## Разработка

Версия — в `VERSION`, изменения — в [CHANGELOG.md](CHANGELOG.md). Компьютеры получают только выпущенные версии (релизы).

1. Правите файлы, в `CHANGELOG.md` добавляете раздел `## X.Y.Z — дата`.
2. `python _setup/release.py X.Y.Z` — версия, коммит, тег, push и релиз на GitHub.

Новые настройки — в `_setup/settings_schema.json` (менеджер сам нарисует поля), в скрипте: `kpsettings.load().get("раздел", "ключ")`.
Менеджер собирается из `_setup/manager/build.cmd`.
Библиотеки `.rtw` собираются из `<плагин>/src/build.cmd` (Visual Studio 2022), готовые `.rtw` лежат в репозитории.
