# Плагины для КОМПАС-3D v25

| Плагин | Что делает |
|---|---|
| Чертежи рам | Чертежи рам из сборок `.a3d`: вид слева и вид справа, ординатные отметки, выноски, таблица профилей |
| Общий PDF стенок | Все стенки из папки — в один PDF с закладками |
| Проверка чертежа | Ищет наложения надписей, выход за рамку, пустые длины и т. п. |
| PDF из чертежей | Несколько `.cdw` — в один PDF |

## Установка на компьютер

1. [Скачать ZIP](https://github.com/greyka/kompas-plugins/archive/refs/heads/main.zip) и распаковать.
2. Закрыть КОМПАС.
3. Запустить `Установить.bat`. Python поставится сам (из интернета), права администратора не нужны.
4. КОМПАС → меню **Приложения** → нужный плагин.

## Обновление

Автоматически при входе в Windows: ярлык «Обновление плагинов КОМПАС» в Автозагрузке.
Вручную: `C:\KompasPlugins\Обновить.bat`. Git на компьютере не нужен.

Подробно — в [ПРОЧТИ.txt](ПРОЧТИ.txt).

## Разработка

Править файлы → `git commit` → `git push`, и все компьютеры получат обновление.
Библиотеки `.rtw` собираются из `<плагин>/src/build.cmd` (Visual Studio 2022), готовые `.rtw` лежат в репозитории.
