# Журнал изменений

Версии: `МАЖОР.МИНОР.ПРАВКА` — правка: исправления; минор: новые возможности; мажор: несовместимые изменения.

## 1.5.3 — 2026-10-24
- Менеджер: кнопка «Проверить» заново читает установленную версию. Раньше, если плагины обновились,
  пока менеджер был открыт, он показывал старую версию и «у вас последняя».

## 1.5.2 — 2026-10-24
- Окна плагинов (выбор файлов и папки, «Сохранить общий чертёж как», сообщения) открываются
  поверх КОМПАС — раньше могли открыться свёрнутыми или спрятаться под окном КОМПАС.
- Общий чертёж: имя по умолчанию — по папке со сборками («Стенки — общий чертёж»),
  а не «Вид слева — общий чертёж»; сохраняется в папку «Чертежи».
- Общий чертёж: если имена файлов совпадают (Ст4 вида слева и Ст4 вида справа) — в штампе
  добавляется папка: «Ст4 — Вид слева», «Ст4 — Вид справа».

## 1.5.1 — 2026-10-24
- **Наименования — из имени файла:**
  - «Общий чертёж»: в штампе каждого листа — имя исходного файла (Ст1, Ст4, Стенка под металл двери…)
    и масса этого чертежа (раньше — «Общий» на всех листах; подпись внизу листа больше не нужна);
  - «Чертежи рам» / «Общий PDF стенок»: в штампе — имя файла сборки, а не наименование из модели
    (настройка «Штамп: наименование» → «Наименование из модели» вернёт как было);
  - закладки общих PDF — по-прежнему имена файлов.

## 1.5.0 — 2026-10-21
- **Общий чертёж:** несколько чертежей → один многолистовой `.cdw` (меню «PDF из чертежей»):
  «Выбрать чертежи → общий чертёж…», «Открытые чертежи → общий чертёж…»,
  «Все чертежи из папки → общий чертёж…».
  Каждый чертёж — отдельный лист своего формата и ориентации; переносится всё как есть, включая
  ручные правки (рама, отметки, размеры, выноски, таблица, штамп). Внизу слева на каждом листе —
  подпись: имя исходного файла, наименование и масса (наименование и масса в штампе многолистового
  документа общие для всех листов, поэтому в штампе — имя общего чертежа).
  Рядом — многостраничный PDF; общий чертёж открывается в КОМПАС (оба — настройки
  «PDF и общий чертёж»).

## 1.4.0 — 2026-10-20
- **Размеры проёмов** (двери, окна): ширина и высота в свету — проём находится по модели сам
  (большой пустой прямоугольник между стойками, перемычкой и низом). Настройка «Размеры проёмов».
- **Исправитель чертежа** (`Проверка чертежа\drawfix.py`) — отдельный скрипт:
  берёт замечания проверки и переносит позиционные выноски на свободные места (с учётом надписей,
  размеров, линий отметок, диагонали, линий других выносок и элементов рамы), сдвигает надписи
  внутрь рамки, убирает лишние нули в сечениях таблицы.
- **Проверка и исправление сразу при построении** («Чертежи рам», «Общий PDF стенок»):
  лист строится → проверяется → исправляется → сохраняется → **PDF делается уже из исправленного
  чертежа**. Что исправить не удалось — в итоговом окне (файл, путь, что осталось) и в справке
  «<имя> — проверка.txt» рядом с чертежом. Настройка «Исправлять чертёж сразу при построении».
- Меню «Проверка чертежа»: **«Исправить текущий чертёж»**, **«Исправить все чертежи в папке…»**
  (для уже готовых чертежей; PDF рядом пересоздаётся из исправленного).
- Сечения без лишних нулей: «□60,00x40,00x5,00» → «□60x40x5».
- Подписи отметок разведены шире (не стоят вплотную).

## 1.3.2 — 2026-10-20
- Обновление работает на компьютерах, где Windows не хватает корневого сертификата GitHub
  (ошибка `CERTIFICATE_VERIFY_FAILED: unable to get local issuer certificate` — отчёт Димы):
  свой набор сертификатов (certifi), а если и он не помог — скачивание через встроенный в Windows `curl.exe`.

## 1.3.1 — 2026-10-20
- Обновление работает, даже если служебный адрес api.github.com недоступен (лимит запросов,
  блокировка у провайдера): версия и архив берутся с обычных страниц github.com.
- Ошибки связи пишутся в журнал «Обновление» — его можно отправить кнопкой «Сообщить о проблеме…».
- Понятный текст в менеджере, если нет связи с GitHub.

## 1.3.0 — 2026-10-20
- **Выбор видов при построении:** «Чертёж рамы из текущей сборки», «Чертежи для всех сборок в папке»
  и «Общий PDF стенок» спрашивают: **Оба вида / Вид слева / Вид справа**.
  Галочка «Больше не спрашивать» запоминает выбор в настройках; включить вопрос снова —
  менеджер → Настройки → «Чертежи рам» (или «Общий PDF стенок») → «Спрашивать при каждом построении».
- **Подробный список проблем** в итоговом окне: для каждой сборки, которую не удалось построить
  или пропустили, — имя файла, полный путь и причина (не открылась, не рама, чертёж уже есть,
  не создался PDF…).

## 1.2.4 — 2026-10-20
- Если КОМПАС на время перестаёт отвечать (не открывает сборку, не создаёт чертёж или вид) —
  плагин ждёт и повторяет (до 3 раз: 2, 5, 10 с), а не пропускает сборки подряд.
  По отчёту: у Димы так выпало 9 сборок из 20.
- Понятный текст ошибки вместо `'NoneType' object has no attribute …`.
- Недостроенный при ошибке чертёж закрывается (не копится скрытым в КОМПАС).
- Сборки без профилей металлоконструкций (сборка блока, пол, потолок…) — не ошибка,
  а «Пропущены — не рамы» в итоговом окне.

## 1.1.0 — 2026-10-19
- **Менеджер плагинов КОМПАС** (`Менеджер плагинов КОМПАС.exe`, ярлыки в меню «Пуск» и на рабочем столе):
  список плагинов, настройки, версия и обновление, журнал изменений.
- **Файл настроек** `settings.ini` в папке плагинов — правится в менеджере или Блокнотом;
  обновления его не трогают.
- Настраивается: какие виды строить, PDF, открывать ли чертежи, подпись вида, отметки по стойкам
  (от начала профиля / по оси), габариты, диагональ, выноски, таблица, крепёж, самый мелкий масштаб,
  наименьший формат, поля штампа (Разраб., Пров., организация), имена папок, перезапись готовых;
  имя общего PDF стенок; пороги «Проверки чертежа»; сортировка и закладки «PDF из чертежей».
- В меню каждого плагина — пункт **«Настройки и версия…»**.
- Версия показывается в окнах плагинов и в менеджере.
- Обновление ставит **только выпущенные версии** (релизы GitHub); канал «последние изменения» — по желанию.
