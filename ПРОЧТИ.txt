ПЛАГИНЫ ДЛЯ КОМПАС-3D
=====================

УСТАНОВКА НА КОМПЬЮТЕР
----------------------
1. Скопируйте всю папку «Плагины» на компьютер (или запустите с флешки).
2. Закройте КОМПАС-3D.
3. Запустите «Установить.bat».
4. Откройте КОМПАС → меню «Приложения» → нужный плагин.

Python ставится автоматически и ОДИН раз (общий для всех плагинов):
  • сначала скачивается из интернета (python.org) — папка «Python\Онлайн»;
  • если интернета нет — ставится из папки «Python\Офлайн».
Нужная версия зашита: Python 3.14.7 + pywin32 312.

Куда ставится:  C:\KompasPlugins\
                  Python\          — общий Python (один на все плагины)
                  Чертежи рам\     — плагин
                  ...              — остальные плагины
(если в C:\ писать нельзя — в %LOCALAPPDATA%\KompasPlugins)
Права администратора не нужны.

После установки папку «Плагины» можно удалить или унести — работает копия
из C:\KompasPlugins.


ПАПКИ
-----
Установить.bat   — установить/обновить все плагины (и Python, если его нет)
Python\Онлайн\   — «Установить Python из интернета.bat» (переустановить вручную)
Python\Офлайн\   — «Установить Python без интернета.bat» + runtime\ (33 МБ).
                   Если интернет везде есть, папку runtime можно удалить.
_setup\          — служебные файлы установщика
<Плагин>\        — по папке на каждый плагин


ОБНОВЛЕНИЕ С GITHUB (автоматически)
-----------------------------------
Плагины хранятся в репозитории https://github.com/greyka/kompas-plugins
После «Установить.bat» компьютер сам проверяет обновления при каждом входе
в Windows (ярлык «Обновление плагинов КОМПАС» в Автозагрузке).
Есть новая версия — она скачивается и ставится, появится окно со списком.
Вручную: C:\KompasPlugins\Обновить.bat
  • если КОМПАС открыт — скрипты обновятся сразу, библиотеки .rtw и новые
    плагины в меню — после перезапуска КОМПАС (для новых плагинов: закрыть
    КОМПАС и ещё раз «Обновить.bat»);
  • git на компьютере не нужен, нужен только интернет.

Для разработчика: правите файлы в этой папке (это git-репозиторий),
затем  git commit  и  git push  — все компьютеры получат обновление.

ОБНОВЛЕНИЕ БЕЗ ИНТЕРНЕТА / НОВЫЙ ПЛАГИН
---------------------------------------
Положите новую или обновлённую папку плагина в «Плагины» и снова
запустите «Установить.bat» (КОМПАС закрыт). Python повторно не ставится.


ПЛАГИНЫ
-------
Чертежи рам — меню «Приложения» → «Чертежи рам»:
  • Чертёж рамы из текущей сборки — для открытой сборки .a3d строит два
    чертежа (вид слева и вид справа) и открывает их;
  • Чертежи для всех сборок в папке... — все .a3d в выбранной папке;
  • Открыть папку «Чертежи».
  Результат: рядом со сборками, «Чертежи\Вид слева\» и «Чертежи\Вид справа\»
  (.cdw + .pdf). Без меню КОМПАС: перетащить папку на
  «Чертежи рам\Пакетно (перетащить папку).bat».


КАК УСТРОЕН ПЛАГИН (для добавления новых)
-----------------------------------------
Папка плагина = plugin.ini + библиотека .rtw + скрипты.
  plugin.ini:   [plugin]
                name    = Название в меню
                library = Файл.rtw
                folder  = Приложения
Установщик находит все папки с plugin.ini, копирует их в C:\KompasPlugins
и подключает .rtw в Менеджер библиотек КОМПАС.
.rtw запускает Python из соседней папки ..\Python.
Исходники и сборка .rtw: <плагин>\src\build.cmd (Visual Studio 2022).
