ПЛАГИНЫ ДЛЯ КОМПАС-3D
=====================

УСТАНОВКА НА КОМПЬЮТЕР
----------------------
1. Скопируйте всю папку «Плагины» на компьютер (или запустите с флешки).
2. Закройте КОМПАС-3D.
3. Запустите «Установить.bat».
4. Откройте КОМПАС → меню «Приложения» → нужный плагин.

Python ставится автоматически и ОДИН раз (общий для всех плагинов):
  • сначала скачивается из интернета (python.org) — папка «Python\Онлайн»;
  • если интернета нет — ставится из папки «Python\Офлайн».
Нужная версия зашита: Python 3.14.7 + pywin32 312.

Куда ставится:  C:\KompasPlugins\
                  Python\          — общий Python (один на все плагины)
                  Чертежи рам\     — плагин
                  ...              — остальные плагины
(если в C:\ писать нельзя — в %LOCALAPPDATA%\KompasPlugins)
Права администратора не нужны.

После установки папку «Плагины» можно удалить или унести — работает копия
из C:\KompasPlugins.


ПАПКИ
-----
Установить.bat   — установить/обновить все плагины (и Python, если его нет)
Python\Онлайн\   — «Установить Python из интернета.bat» (переустановить вручную)
Python\Офлайн\   — «Установить Python без интернета.bat» + runtime\ (33 МБ).
                   Если интернет везде есть, папку runtime можно удалить.
_setup\          — служебные файлы установщика
<Плагин>\        — по папке на каждый плагин


МЕНЕДЖЕР ПЛАГИНОВ И НАСТРОЙКИ
-----------------------------
«Менеджер плагинов КОМПАС» — ярлык на рабочем столе и в меню «Пуск»
(или пункт «Настройки и версия...» в меню любого плагина в КОМПАС):
  • Плагины            — что установлено, подключить в КОМПАС заново;
  • Настройки          — всё, что можно настроить, по разделам;
  • Версия и обновление — установленная версия, новая на GitHub, «Обновить»;
  • Что нового         — журнал изменений (CHANGELOG.md).
Настройки хранятся в файле C:\KompasPlugins\settings.ini — его можно
править и Блокнотом. Обновления этот файл не трогают.

ОШИБКИ — СРАЗУ РАЗРАБОТЧИКУ
---------------------------
Если в плагине что-то сломалось, появится окно с текстом ошибки:
напишите, что делали, и нажмите «Отправить разработчику» — описание,
версия, компьютер и журнал уйдут в Telegram (бот @lider_house_debug_bot).
Без ошибки: менеджер → «Плагины» → «Сообщить о проблеме…».
Журналы: %LOCALAPPDATA%\KompasPlugins\logs\<плагин>.log
Для разработчика — забрать отчёты:
  python _setup\report.py --inbox C:\Users\Greyka\Desktop\Project\Kompas\reports

ВЕРСИИ И ОБНОВЛЕНИЕ С GITHUB (автоматически)
--------------------------------------------
Номер версии — в файле VERSION (например 1.1.0), список изменений —
CHANGELOG.md. Плагины хранятся в https://github.com/greyka/kompas-plugins
Компьютер сам проверяет обновления при каждом входе в Windows (ярлык
«Обновление плагинов КОМПАС» в Автозагрузке; выключается в менеджере).
По умолчанию ставятся только ВЫПУЩЕННЫЕ версии (релизы GitHub).
Вручную: менеджер → «Версия и обновление» → «Обновить», или Обновить.bat.
  • если КОМПАС открыт — скрипты обновятся сразу, библиотеки .rtw и новые
    плагины в меню — после перезапуска КОМПАС (для новых плагинов: закрыть
    КОМПАС и ещё раз «Обновить»);
  • git на компьютере не нужен, нужен только интернет.

Для разработчика (выпуск версии):
  1. правите файлы в этой папке (это git-репозиторий);
  2. в CHANGELOG.md добавляете раздел «## 1.2.0 — дата» со списком изменений;
  3. python _setup\release.py 1.2.0
     (запишет VERSION, коммит, тег v1.2.0, push, релиз на GitHub).
  Новые настройки описываются в _setup\settings_schema.json — менеджер сам
  покажет для них поля; в скрипте: kpsettings.load().get("раздел", "ключ").
  Менеджер собирается из _setup\manager\build.cmd, .rtw — <плагин>\src\build.cmd.

ОБНОВЛЕНИЕ БЕЗ ИНТЕРНЕТА / НОВЫЙ ПЛАГИН
---------------------------------------
Положите новую или обновлённую папку плагина в «Плагины» и снова
запустите «Установить.bat» (КОМПАС закрыт). Python повторно не ставится.


ПЛАГИНЫ
-------
Чертежи рам — меню «Приложения» → «Чертежи рам»:
  • Чертёж рамы из текущей сборки — для открытой сборки .a3d строит два
    чертежа (вид слева и вид справа) и открывает их;
  • Чертежи для всех сборок в папке... — все .a3d в выбранной папке;
  • Открыть папку «Чертежи».
  Результат: рядом со сборками, «Чертежи\Вид слева\» и «Чертежи\Вид справа\»
  (.cdw + .pdf). Без меню КОМПАС: перетащить папку на
  «Чертежи рам\Пакетно (перетащить папку).bat».
  Перед построением спрашивает, какие виды делать (можно запомнить).
  На листе: отметки, габариты, диагональ, размеры проёмов (двери/окна),
  выноски позиций, таблица профилей.
  Каждый лист сразу проверяется и исправляется (выноски переносятся на
  свободные места), и только потом сохраняется и делается PDF.
  Что исправить не удалось — в итоговом окне и в «<имя> — проверка.txt».

Проверка чертежа — меню «Приложения» → «Проверка чертежа»:
  • Проверить текущий чертёж / все чертежи в папке... — только справка,
    чертёж не меняется;
  • Исправить текущий чертёж / все чертежи в папке... — исправитель
    (drawfix.py): переносит выноски, убирает лишние нули в сечениях;
    PDF рядом с чертежом пересоздаётся из исправленного.

Общий PDF стенок, PDF из чертежей — один PDF с закладками на папку.


КАК УСТРОЕН ПЛАГИН (для добавления новых)
-----------------------------------------
Папка плагина = plugin.ini + библиотека .rtw + скрипты.
  plugin.ini:   [plugin]
                name    = Название в меню
                library = Файл.rtw
                folder  = Приложения
Установщик находит все папки с plugin.ini, копирует их в C:\KompasPlugins
и подключает .rtw в Менеджер библиотек КОМПАС.
.rtw запускает Python из соседней папки ..\Python.
Исходники и сборка .rtw: <плагин>\src\build.cmd (Visual Studio 2022).
